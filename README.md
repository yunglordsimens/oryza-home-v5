# Oryza

Landing page for Oryza — café, bistro, bar in Prague (Lihovar, Národní).

- `/` — current version (V5), languages: Czech, English, Vietnamese
- `/v4/` — previous version (V4), kept for reference
- `/assets/` — brand fonts (Alterglam, Inter)

Static site (no build step). Deploy: GitHub Pages / Vercel from the repo root.
